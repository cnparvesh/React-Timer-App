# ⏱️ React Timer App using useRef & useState

A simple and beginner-friendly **Timer (Stopwatch) App** built with **React** using  
`useState`, `useRef`, and `useEffect`.  
Perfect for understanding how timers work in React! 🚀

---

## 🧠 What You Will Learn

✅ How to use `useState` for updating UI  
✅ How to use `useRef` to store mutable values  
✅ How `setInterval` & `clearInterval` work  
✅ How to clean up memory using `useEffect`  
✅ How to build a real working Timer in React  

---

## ✨ Features

⏴ Start the timer  
⏸ Stop the timer  
🔁 Reset the timer  
🧠 Prevents multiple intervals  
🧹 Auto cleanup on component unmount  
⚡ Super fast & lightweight  

---

## 🛠️ Tech Stack

- ⚛️ React JS  
- 🎯 JavaScript  
- 🎨 CSS (Animated gradient + glassmorphism)  
- 🧩 React Hooks: `useState`, `useRef`, `useEffect`
