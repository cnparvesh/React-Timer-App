# React-Timer-App

A simple and beginner-friendly Timer (Stopwatch) App built with React using
useState, useRef, and useEffect.
Perfect for understanding how timers work in React! 🚀

✨ Features

⏴ Start the timer
⏸ Stop the timer
🔁 Reset the timer
🧠 Prevents multiple intervals
🧹 Auto cleanup on component unmount
⚡ Super fast & lightweight

🛠️ Tech Stack

⚛️ React JS

🎯 JavaScript

🎨 Inline CSS

🧩 React Hooks: useState, useRef, useEffect.
